# Desktop-only polish contradicts a UX claim

**Claim:** The report says a portfolio that traps keyboard users, hides focus, breaks at zoom, or forces motion contradicts a user-centered claim.

**Sources:** Winning-portfolios report (attachment `deep-research-report__10_.md`).

## Evidence

**Inferred (pitfall):** “Desktop-only polish” undermines claims of UX competence. The better move named is to test responsive reflow, keyboard use, zoom, and focus.

**Borrowed:** WCAG guidance, as the report summarizes it, calls for keyboard operability, visible keyboard focus, and layouts that reflow under magnification rather than requiring two-dimensional scrolling.

## Implication for this portfolio

This is a quality bar for the newsite panels, not a visual theme. It is not a finding that the featured homepages passed those tests.

## Limit

The report did not run that test on the twelve sites. See `../accessibility/signal-is-not-an-audit.md`.
