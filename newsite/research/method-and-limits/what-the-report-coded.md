# What the report coded

**Claim:** The report’s percentages come from a manual code of 12 sites against a fixed list of dimensions. Where the page was countable, it counted. Where judgment was required, it described a pattern.

**Sources:** Winning-portfolios report (attachment `deep-research-report__10_.md`).

## Evidence

**Observed coding frame:**

| Dimension | How the report interpreted it |
| --- | --- |
| Structure | Homepage information architecture, work hierarchy, about and credibility, contact path |
| Case-study length | Major narrative blocks, not raw HTML word counts |
| Project count | Work entries deliberately exposed from the home page |
| Visuals | Presence, purpose, and the relationship between product imagery and prose |
| Storytelling | Hook, problem framing, narrative progression, tension, resolution |
| Process artifacts | Research, flows, sketches, wireframes, prototypes, systems, decision logs, tests, QA |
| Metrics | Behavioral, usability, business, scale, operational, or delivery measures |
| Tools | Whether tools are foregrounded and what role they play |
| Interaction patterns | Bespoke portfolio interactions versus conventional navigation |
| Accessibility | Explicit claims or observable signals only, not a WCAG audit |
| Responsiveness | Evidence on the pages reviewed, not an exhaustive device audit |
| Personal branding | Role clarity, memorable point of view, visual or verbal differentiation |
| Résumé / contact | Clearly exposed conversion routes |
| Seniority evidence | Scope, autonomy, systems thinking, leadership, influence, duration of impact |

The countable signals are in the files under `proof-and-metrics/`, `navigation/`, `accessibility/`, and `interaction-and-tools/`.

## Implication for this portfolio

If a percentage appears in this library, it is one of those codes or it is not from this report. Do not invent a fifteenth dimension.

## Limit

The homepage notes did not use this codebook. Their evidence IDs are E1–E10, defined in `newsite/research.md`.
