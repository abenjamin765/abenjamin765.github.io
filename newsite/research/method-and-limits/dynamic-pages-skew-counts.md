# Raw page length is a poor measure

**Claim:** Case “length” in the report means major narrative blocks, because dynamic pages can repeat or hide text.

**Sources:** Winning-portfolios report (attachment `deep-research-report__10_.md`).

## Evidence

**Observed (report):** Several portfolios use JavaScript, animation, or repeated responsive markup, so raw HTML length and exact visual counts can mislead. The report uses major narrative sections as a depth proxy and separates home-page work links from full case studies.

**Observed range:** Compact cases with roughly four to six major narrative blocks, for example Niklas Peterson’s LottieFiles story and Aditya Muralidhar’s category-discovery case. Rishabh Yadav’s DayUp case is organized into 13 numbered sections. Manolo Beviá’s Cornell case is also extensive: research, content audit, IA, testing, user and task flows, visual design, development, accessibility, and outcomes.

## Implication for this portfolio

Do not target a word count or a page count for a work story. Decide which blocks the story needs, then stop.

## Limit

“Four to six” and “13” are the report’s structural counts, not timed reading studies. The homepage notes did not measure case length at all.
