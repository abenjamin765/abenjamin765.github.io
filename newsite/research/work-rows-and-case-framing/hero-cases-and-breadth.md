# Hero cases and a breadth layer are not the same count

**Claim:** The report separates a few hiring-critical stories from a wider set of visible work. The homepage notes did not set a case-study count.

**Sources:** Winning-portfolios report (attachment `deep-research-report__10_.md`); contrast with `newsite/research.md`.

## Evidence

**Observed (report):** Visible work entries on the home page ranged from about 3 to 11, median 6.5. Project count means visible work or project entries, including side or archived work when presented as portfolio work, and excluding “coming soon” placeholders.

**Observed examples (report):** Vaibhav presents four strongly quantified selected projects. Dharmesh exposes five shipped initiatives. Aditya presents three primary projects plus two secondary projects. Niklas exposes ten case-study links; the report says his staff-level stories can be exceptionally concise. Pranshu has a large professional and side-project set where much of the value is visual breadth and experimentation.

**Inferred (report):** The actionable model is 2–4 hiring-critical “hero” stories plus an optional breadth layer, not equal weight for every project. The report says this reconciles the Wall observation with AIGA’s earlier reporting that new UX hires commonly showed a handful of detailed projects. That AIGA point is borrowed.

**P0 check (report, prescriptive):** Choose 2–4 hero cases, each proving a different hiring-relevant capability.

## Disagreement

The median 6.5 is a count of visible entries, not a recommendation to write six long cases. The homepage notes never recommend 2–4, because they did not review interiors. Using 2–4 as a requirement for this site upgrades the report’s synthesis into a rule the homepage pass did not make.

## Implication for this portfolio

The work panel can show more rows than the number of deep stories. The notes’ row unit still applies to each visible item. How many of those rows open into long cases is not settled by the homepage notes.

## Limit

Median 6.5 on 12 sites is descriptive of that sample. “2–4” is the report’s recommended hero tier, and the level tables later in the report vary it (entry 2–3, mid and senior 3–4, lead 3 product/strategy plus 1 leadership story, staff and principal 3–5).
