# Seven principles the report wants codified

**Claim:** The report proposes seven shared principles and a practical consequence for each. They are a synthesis, not a count from portfolios.

**Sources:** Metro × Apple design-system report (attachment `deep-research-report__11_.md`).

## Evidence

**Prescribed:**

| Principle | Consequence the report names |
| --- | --- |
| Content is primary | Do not wrap every object in cards, borders, or glass. |
| Clarity before decoration | A visual effect must improve hierarchy, feedback, or orientation. |
| Typography creates hierarchy | Type roles are semantic tokens. |
| Motion explains change | Animate relationships and state, not decoration. |
| Design for the actual medium | Do not force web metaphors into native apps, or the reverse. |
| Semantics survive platform changes | Share `text-primary`, not a fixed gray hex. |
| Native affordance beats visual sameness | Fonts, icons, radii, materials, and navigation may differ by platform. |

The Metro and Apple columns in the report’s table are borrowed summaries. See `three-layers.md`.

## Implication for this portfolio

On this web portfolio, the usable lines are: type and spacing before containers, motion that explains a change, and no effect whose only job is decoration. Native Apple or Windows controls are out of scope for `newsite/`.

## Limit

The report does not test these principles against the Wall homepages.
