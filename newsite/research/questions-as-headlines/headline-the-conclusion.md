# Headline the section with the conclusion

**Claim:** The report treats a wall of prose as a failure, and the remedy it names is to headline each section with the conclusion.

**Sources:** Winning-portfolios report (attachment `deep-research-report__10_.md`).

## Evidence

**Inferred (report pitfall):** “Wall of prose” hurts because the reviewer cannot extract the argument quickly. The better move listed is: headline each section with the conclusion.

**Inferred (report):** Strong case sequences are evidence, then changed understanding, then competing options, then decision, then consequence. A generic Research → Persona → Journey Map → Wireframes → UI sequence proves only that the author knows standard UX activities.

**Observed examples of conclusion-shaped headings:** “Scoping down to ship” (Dharmesh). “The day Copilot stopped answering questions and started doing work” (Eemon). “Curation without visibility is just inventory no one sees.” (Aditya).

## Implication for this portfolio

If a work story has sections, the heading should state the decision or the result. The homepage notes do not test this, because they did not read interiors. Their matching instruction is about the row, not the interior heading.

## Limit

No scan study compared conclusion headings with topic headings. This is a prescriptive reading of the sample.
