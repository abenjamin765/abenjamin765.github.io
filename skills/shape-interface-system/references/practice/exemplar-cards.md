# Exemplar cards

Use this reference when award-winning apps, competitor interfaces, mood boards, screenshots, or aspirational products inform a direction.

## Rule

An exemplar is evidence of a reasoning pattern, not permission to copy its surface treatment. Award status shows that a publisher or jury valued the work; it does not establish which treatment caused user success.

For each consequential exemplar, record:

| Field | Question |
| --- | --- |
| Problem and audience | What user purpose or context does it serve? |
| Platform advantage | What device, input, system component, or capability does it exploit? |
| Hierarchy and visual grammar | How are attention, grouping, density, type, color, material, and imagery organized? |
| Interaction mechanism | What makes control, feedback, recovery, or navigation understandable? |
| Accessibility | Which abilities, preferences, modalities, or task paths are supported? |
| Emotional aim | What feeling does the design reinforce, and through which repeated decisions? |
| Transferable pattern | Which principle could improve this product? |
| Non-transferable treatment | Which branded, cultural, platform-specific, or copyrighted expression must not be copied? |
| Evidence gap | What outcome, alternative, or usability evidence is missing? |
| Provenance | Source, publisher, date, URL, and review date |

Triangulate important directions with more than one source class when practical: platform guidance, a relevant exemplar, and project evidence. A gallery of similar screenshots narrows taste; a small set of contrasting, annotated cases improves judgment.

## 2026 Apple Design Award examples

Use the [official awards page](https://developer.apple.com/design/awards/) for current descriptions. These examples illustrate different transferable patterns:

- **grug:** narrow purpose, removal of extraneous account machinery, and hand-drawn character reinforcing a playful idea.
- **Guitar Wiz:** VoiceOver, Dynamic Type, increased contrast, and differentiation without color integrated into the primary musical tasks.
- **Moonlitt:** simple onboarding and interaction tailored across several Apple platforms.
- **Tide Guide:** dense environmental data made legible through charts, widgets, custom animation, and a cohesive aquatic palette.
- **Primary:** restraint that keeps attention on news rather than spatial chrome.

Do not infer that these products share a visual formula. Their common strength is fit among purpose, platform, interaction, accessibility, and character.

When a request depends on the latest or current winners, refresh the official source if retrieval is available and permitted. If it is unavailable, label the last verified date and preserve recency as evidence debt instead of implying currency. Historical examples may still support durable reasoning when outdated platform details are clearly labeled.
