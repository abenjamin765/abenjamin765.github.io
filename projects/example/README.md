# Example project

Blank starter for a new initiative. Copy this directory (or recreate the layout from [`../README.md`](../README.md)), then replace this file with your problem statement.

For a finished public walkthrough, see [`../demo/`](../demo/) (Library Holds).

Local skills and agent overrides belong under `overrides/` until evidence supports an upstream contribution. Put secrets and confidential knowledge in `private/` (gitignored) or another controlled repository — never in the public Many Hats demo.
