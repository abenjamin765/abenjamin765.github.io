# Many Hats v0.1 — release notes

Early public foundation of **Many Hats**: a cloneable AI product team with portable skills, named specialists, multi-host adapters, and a fictional Library Holds demo.

Repository: https://github.com/abenjamin765/many-hats  
(Previously drafted under the working name Open Product Team; GitHub slug renamed to `many-hats`. Old URLs redirect.)

## What’s in v0.1

- 13 agents with stable role boundaries and hat avatars
- 15 portable skills with contracts and baseline evals
- Shared skill mount at `.agents/skills/` plus Claude / Cursor / Copilot / Windsurf adapters
- Public demo: [`projects/demo/`](../projects/demo/) (Library Holds)
- Human authority preserved in [`AGENTS.md`](../AGENTS.md)
